# Handoff: صفحة الباقات v2 — شاشة واحدة ميسّرة لكبار السن

## Overview
تطوير معتمد لصفحة باقات مركز رواد المستقبل للأطفال (futurepioneers2030/futurepioneers-baqat).
الاتجاه المعتمد: **شاشة واحدة بدون أي تنقّل** — مفتاحا «الفترة» و«المدة» ثابتان أعلى الصفحة،
والبطاقات تتحدث فوراً. الهدف: وصول العميل (خصوصاً كبار السن) إلى «اشترك الآن» الصحيح بأقل خطوات،
بخط وأزرار أكبر، وبدون شاشة اختيار فترة وسيطة وبدون زر «تغيير الفترة».

## About the Design Files
الملف المرفق `main-baqat.dc.html` **مرجع تصميمي بصيغة HTML** (نموذج تفاعلي يوضح الشكل والسلوك المقصودين)
وليس كوداً إنتاجياً يُنسخ كما هو. المطلوب **إعادة بناء هذا التصميم داخل بيئة المستودع القائمة**:
- مصدر الحقيقة يبقى `data/packages.json` (لا تُدخل الأسعار/الروابط يدوياً في HTML).
- المولّد `src/build.mjs` يولّد `site/index.html` و`site/embed.html`.
- التصميم المرجعي للمقارنة في `design_handoff_baqat/reference-design.html` — حدّثه ليطابق v2 وإلا سيفشل `src/verify.mjs`.
- الصفحة تُلصق في محرر HTML بمتجر سلة، لذا **يفضَّل إبقاؤها بدون JavaScript** — كل التفاعل قابل للتنفيذ
  بـ radio inputs مخفية + CSS `:checked` كما في النسخة الحالية تماماً (التفصيل أدناه).

## Fidelity
**High-fidelity (hifi).** الألوان والخطوط والمقاسات والنصوص نهائية ومعتمدة من العميل — انقلها كما هي.

## Interactions & Behavior
- تبديل «الفترة»: يغيّر عنوان القسم، روابط «اشترك الآن»، ورابط «تصفح كل باقات…». **الأسعار نفسها في الفترتين** (حقيقة بيانات).
- تبديل «المدة»: يغيّر السعر والوصف والرابط في كل بطاقة، ويُظهر/يُخفي بطاقة «ساعة واحدة» (تظهر مع «اليوم» فقط).
- لا صفحات ولا رجوع ولا تمرير لأعلى مطلوب — اللوحة sticky فتبقى الأزرار في متناول اليد أثناء التمرير.
- hover للبطاقات والأزرار كما في المواصفات أعلاه؛ transitions بمدة .2s و.15s فقط، بلا حركات أخرى.
- كل روابط المنتجات تفتح صفحة المنتج في سلة (في نفس التبويب داخل المتجر كما هو معمول به حالياً).

### التنفيذ بدون JavaScript (الموصى به — مطابق لنمط النسخة الحالية)
- radio مخفية: `rw-p-m` (checked افتراضياً) و`rw-p-e` باسم `rw-period`؛ و`rw-d-day` (checked) /`rw-d-week`/`rw-d-month`/`rw-d-term` باسم `rw-dur`. أزرار الـsegmented هي `<label for="…">`.
- كل بطاقة تحتوي 4 (أو 8) متغيرات `.rw-v` كما اليوم، لكن **لكل فترة نسختها من الروابط**: الأبسط
  توليد شبكتين (صباحية/مسائية) وإظهار إحداهما بـ`:checked ~`، مع عنواني «باقات الفترة…» بنفس الآلية.
- بطاقة «ساعة واحدة» تُغلَّف بـ`.rw-v.rw-v-day` فقط (بدل `.rw-va` الدائمة) — استخدم `display:contents` للفئة الظاهرة كي لا تكسر الشبكة.
- حدّث فحوصات `src/verify.mjs`: الشبكة لم تعد 6 أعمدة (صارت 3/2/1 عند 900px و560px)، وشارة الساعة حُذفت،
  والنص التعريفي تغيّر، وعدد روابط المنتجات يبقى 42 + رابطي قسم (رابط القسم يظهر مرة لكل فترة).

## State Management
حالتان فقط: `period ∈ {morning, evening}` (افتراضي morning) و`duration ∈ {day, week, month, term}` (افتراضي day).
بلا JS تكونان radio inputs؛ في بيئة مكوّنات تكونان state محلية. لا جلب بيانات — كل شيء يُولَّد وقت البناء من `packages.json`.
