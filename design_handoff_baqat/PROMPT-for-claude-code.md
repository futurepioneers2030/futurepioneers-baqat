# برومبت جاهز — انسخه والصقه في Claude Code

افتح Claude Code داخل مجلد `design_handoff_baqat` (أو مجلد يحتويه) والصق التالي:

---

اقرأ أولًا `README.md` ثم `reference-design.html` و`data/packages.json` في هذا المجلد.

المطلوب: إنشاء موقع ثابت (static) خاص بصفحة باقات «مركز رواد المستقبل للأطفال» جاهز للنشر:

1. أنشئ مجلد `site/` فيه `index.html` يطابق `reference-design.html` بالبكسل (نفس الألوان والخطوط والنصوص العربية حرفيًا — لا تعد صياغة أي نص).
2. ولّد بطاقات الباقات الـ 42 برمجيًا من `data/packages.json` بدل النسخ اليدوي (سكربت build بسيط بـ Node يولّد HTML ثابتًا، أو JS خفيف يقرأ JSON مضمّنًا في الصفحة) — بحيث أي تعديل سعر أو رابط مستقبلًا يكون في JSON فقط.
3. حافظ على عمل الصفحة بدون JavaScript إن أمكن (المرجع يعمل بـ CSS فقط عبر radio inputs) — وإن استخدمت JS فأبقِ التدهور سلسًا.
4. الصفحة RTL بالكامل، خطوط Google Fonts: Baloo Bhaijaan 2 + Almarai، وأهداف اللمس ≥ 44px، ونقاط التحول: 6 أعمدة > 1019px، ثم 3، ثم عمودان ≤ 600px.
5. أضف `CLAUDE.md` في جذر المشروع يلخص: بنية الملفات، أن `packages.json` هو مصدر الحقيقة للأسعار والروابط، وكيفية إعادة البناء بعد تعديله.
6. اختبر محليًا وتأكد أن كل زر «اشترك الآن» يفتح رابط المنتج الصحيح من JSON، ثم اقترح خطوات النشر (GitHub Pages أو Vercel أو Cloudflare Pages).

ملاحظة: إن كان لديك codebase قائم تريد إضافة الصفحة له، أخبر Claude Code بمساره واطلب اتباع أنماطه بدل إنشاء `site/` جديد.
