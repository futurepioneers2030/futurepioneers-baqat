# Handoff: صفحة باقات مركز رواد المستقبل للأطفال

## نظرة عامة
صفحة هبوط (landing page) مستقلة لعرض باقات اشتراكات مركز رواد المستقبل للأطفال (حضانة وروضة في المدينة المنورة، متجرها على منصة سلة: https://futurepioneers.net).

المشكلة التي تحلها الصفحة: ترتيب المنتجات داخل سلة عشوائي، والعميلة تتوه بين 42 منتجًا. الصفحة تنظّم الوصول في 3 خطوات: اختيار الفترة (صباحية/مسائية) ← اختيار المدة (اليوم/الأسبوع/الشهر/الترم) ← بطاقة الباقة وزر «اشترك الآن» الذي يفتح صفحة شراء المنتج الصحيح مباشرة في سلة.

## عن الملفات المرفقة
الملفات هنا **مراجع تصميم بصيغة HTML** وليست بالضرورة الكود النهائي:

- `reference-design.html` — التصميم المرجعي الكامل والنهائي. ملف واحد مكتفٍ بذاته، **بدون أي JavaScript** (كل التفاعل CSS فقط عبر radio inputs مخفية)، وكل الـ 42 رابط منتج نهائية وصحيحة داخله.
- `data/packages.json` — كل البيانات مهيكلة: الفترات، الباقات، الأسعار، روابط المنتجات الـ 42، بيانات التواصل.

**المطلوب من Claude Code:** إنشاء صفحة ويب خاصة بالمشروع من هذا المرجع. أبسط طريق صحيح: اعتماد `reference-design.html` نفسه كـ `index.html` (يعمل كما هو على أي استضافة ثابتة). الطريق الأفضل للصيانة: توليد بطاقات الباقات برمجيًا من `data/packages.json` بنفس التصميم حرفيًا، بحيث تعديل سعر أو رابط مستقبلًا يكون في ملف JSON فقط. لا حاجة لأي framework — HTML/CSS/JS ثابت يكفي، إلا إذا كان هناك codebase قائم فيُتبع نمطه.

## مستوى الدقة (Fidelity)
**High-fidelity** — التصميم نهائي ومعتمد من العميل: الألوان والخطوط والمقاسات والنصوص كلها نهائية. أعد إنتاجه مطابقًا بالبكسل. النصوص العربية تُنسخ حرفيًا كما في المرجع (لا تُعاد صياغتها).

## الشاشات

### 1. شاشة الهبوط (اختيار الفترة)
- شريط علوي متدرج: `linear-gradient(90deg,#941249,#D60859 45%,#E8BD4B)`، ارتفاع 10px.
- Hero بخلفية كريمية `#FBF2E7`: شعار المركز (من CDN سلة، ارتفاع 96px)، عنوان «دليل أسعار الاشتراكات» (Baloo Bhaijaan 2، وزن 800، `clamp(30px,6vw,44px)`، لون `#D60859`)، سطر «باقات مرنة تناسب احتياج طفلك وأسرتك»، ثم شارة pill «الساعه 25 ريال» (خلفية `#D60859`، نص أبيض 18px، محاطة بنجمتين ذهبيتين ✦ SVG).
- عنوان «اختر الفترة المناسبة» + سطر مساعد «نفس الباقات متوفرة في الفترتين…».
- بطاقتا فترة كبيرتان (grid عمودان، minmax 255px، gap 16px، min-height 200px، radius 26px):
  - **الصباحية**: تدرج `linear-gradient(165deg,#FFF7E8,#FFEBC7)`، حد `2px solid #E8BD4B`، أيقونة شمس SVG ذهبية 52px، العنوان `#941249`، سطر «باقات اليوم والأسبوع والشهر والترم»، رابط «عرض الباقات ←» بلون `#D60859`.
  - **المسائية**: تدرج `linear-gradient(165deg,#941249,#5E0B30)`، أيقونة هلال ذهبية، العنوان أبيض، السطر `#F3D9E4`، «عرض الباقات ←» بلون `#E8BD4B`.
  - hover: `translateY(-4px)` + ظل ملون.
- شريحتا chips: «التقسيط متاح عبر تابي وتمارا» و«اشتراك مرن بدون تجديد تلقائي» (خلفية بيضاء، حد `#EAD9C6`، radius 999px).

### 2. شاشة الباقات (لكل فترة)
- بانر الفترة (radius 20px، flex space-between): اسم الفترة + أيقونتها، وزر «تغيير الفترة» (حد `1.5px solid currentColor`، شفاف) يعيد لشاشة الهبوط. ألوان البانر: صباحي = تدرج كريمي/ذهبي ونص `#941249`؛ مسائي = تدرج عنابي ونص أبيض.
- تبويبات المدة: حاوية بيضاء pill (حد `#EAD9C6`، padding 6px، max-width 560px) فيها 4 تبويبات: اليوم / الأسبوع / الشهر / الترم. النشط: خلفية `#D60859`، نص أبيض، ظل `0 4px 14px rgba(214,8,89,.25)`. غير النشط: شفاف، نص `#941249`. min-height 44px (هدف لمس).
- شبكة 6 بطاقات: «ساعة واحدة» (ثابتة في كل التبويبات) + 4/5/6/8/10 ساعات.
  - أعمدة الشبكة: 6 أعمدة فوق 1019px، 3 أعمدة حتى 1019px (آيباد)، عمودان حتى 600px (جوال). gap 14px، max-width 960px.
  - البطاقة: خلفية بيضاء، حد `1.5px solid #F0DECC`، radius 22px، padding `20px 14px 14px`، محتوى مركزي بعمود gap 10px. hover: `translateY(-3px)` + ظل خفيف.
  - محتوى البطاقة: اسم الباقة (Baloo 800، 23px، `#D60859`) ← فاصل ذهبي 44×3px ← السعر (Baloo 800، 33px، `#2A1B22`) بجانبه «ريال» (13.5px، `#4A323E`) ← وصف المدة «في اليوم/في الأسبوع/…» (13px) ← زر «اشترك الآن» (عرض كامل، min-height 44px، خلفية `#D60859`، نص أبيض 800/15px، radius 999px، hover: `#941249`) — **href = رابط المنتج المحدد من packages.json**.
- تحت الشبكة: رابط «تصفح كل باقات الفترة … في المتجر ↗» إلى رابط قسم الفترة في سلة.

### 3. التذييل (ثابت في كل الشاشات)
- خلفية بيضاء بحد علوي `#F0DECC`. عنوان «تواصل معنا».
- 3 أزرار pill (min-height 46px): واتساب (ممتلئ `#D60859` + أيقونة)، «اتصال 0591044434» (حد `#941249`)، «موقعنا على الخريطة» (حد `#E8BD4B`، نص `#941249`). الروابط في packages.json → contact.
- سطر العنوان والدوام، ثم اسم المركز، ثم شريط متدرج سفلي معكوس.

## التفاعل والسلوك
- الحالة: فترة مختارة (لا شيء/صباحي/مسائي) + مدة مختارة لكل فترة (افتراضي: اليوم). في المرجع منفذة بـ CSS فقط (radio + `:checked ~`)؛ يجوز إعادة تنفيذها بـ JS بسيط بنفس السلوك.
- اختيار الفترة يخفي شاشة الهبوط ويظهر شاشة الباقات؛ «تغيير الفترة» يعكس ذلك. تبديل التبويب يبدّل السعر والوصف ورابط الزر في كل بطاقة فورًا (بدون انتقال صفحة).
- كل الانتقالات transitions بسيطة `.2s` (hover فقط) — لا أنيميشن أخرى.
- الصفحة RTL بالكامل (`dir="rtl"`)، الأرقام غربية (0-9).
