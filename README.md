# باقات مركز رواد المستقبل للأطفال

صفحة تعرض باقات اشتراكات المركز (حضانة وروضة في المدينة المنورة) وتوصل العميل إلى المنتج
الصحيح في متجر سلة.

**«مرشد الباقات»** يسأل ثلاثة أسئلة قصيرة — الفترة ← عدد الساعات ← مدة الاشتراك — ثم يعرض
الباقة وسعرها وزر «اشترك الآن». ومن يعرف ما يريد يفتح جدول الأسعار الكامل بزر واحد.

كل خيار موصوف بلغة الأسرة («6 ساعات — يوم دراسي كامل»)، ومع كل مدة **توفيرها محسوبًا من الأسعار**
(«أوفر بـ550 ريال مقابل أربعة أسابيع»). وفيه زر رجوع، ومخرج «لست متأكد؟» يقترح ويطلب التأكيد،
وبديل قريب بعد النتيجة.

الصفحة تعمل **بدون JavaScript** أيضًا: جدول الأسعار كامل بالـ42 رابطًا موجود في HTML الثابت،
والمحادثة تحسين تدريجي فوقه.

## التشغيل

```bash
npm run check
```

يبني `site/` من `data/packages.json` ثم يشغّل فحوصات التحقق.

```bash
npm run serve
```

معاينة محلية على `http://localhost:4173`.

## النشر

تلقائي: كل `git push` يشغّل بناءً وتحققًا ثم ينشر على Cloudflare Pages.
`main` ← [futurepioneers-baqat.pages.dev](https://futurepioneers-baqat.pages.dev) ·
أي فرع آخر ← رابط معاينة باسم الفرع. **فشل التحقق يوقف النشر.**

للنشر اليدوي من الجهاز: `npm run deploy`.

## تعديل الأسعار أو الروابط

عدّل `data/packages.json` **فقط** ثم ادفع. يصل التعديل إلى المحادثة وإلى جدول الأسعار معًا،
لأن كليهما مولَّد من الملف نفسه. ملفات `site/` مولَّدة (خارج Git) ولا تُحرَّر يدويًا.
